## Description

Why P0: this is the product. Charter goal, criteria 1, 2, 4, 5, 6. Scope: a Timer screen showing a countdown that defaults to 25:00 (or the saved focus length from Settings), with Start, Pause and Reset controls and a Focus/Break label. The countdown is driven by wall-clock time (compare timestamps), not tick counts, so it stays accurate when the tab is backgrounded (charter risk). End of focus per Q-0001 (answered: wait for the user): at 0:00 the label switches to Break, an in-page sound plays once if sound is enabled, the countdown shows the configured break length, and nothing runs until the user presses Start. Light and dark mode. No network calls at runtime. Built in parallel with the Settings item (same cycle, two engineers): shared files such as the app shell, design tokens and the settings storage module are the Chief Architect's to assign in the spec; this item does not decide the stack or file layout. Non-goals: notifications beyond the in-page sound, pomodoro counting, long breaks, history.

## Acceptance criteria

- [ ] (Charter 1) With focus set to 1 minute, a Playwright run presses Start and measures wall-clock time until the label reads Break (the observable end of focus; at that instant the display already shows the break length, per Q-0001); the measured duration is within 1 s of 60 s.
- [ ] (Charter 1, Q-0001) At 0:00 the countdown shows the configured break length and does not count down until Start is pressed again; with sound enabled an in-page sound plays once at 0:00 (the test presses Start first so autoplay rules do not block it).
- [ ] (Charter 2) Start, Pause, Reset each change the display as named; one primary button that toggles between Start and Pause satisfies this. Start begins the countdown from 25:00 by default and the button then reads Pause; Pause freezes the display, the label reads Paused and the button reads Start; Start after Pause resumes from the paused value (within 1 s) and the label returns to Focus or Break; Reset stops the countdown and returns the display to the configured focus length with the label reading Focus.
- [ ] (Charter 4) At 390 px width, in light and in dark mode, there is no horizontal scroll and the countdown, the Start/Pause button, Reset and the label are all visible without scrolling.
- [ ] (Charter 6) axe-core reports zero serious or critical violations on the Timer screen in light mode and in dark mode.
- [ ] (Charter 6) Every Timer control is reachable by Tab, operable by Enter or Space, and shows a visible focus ring when focused.
- [ ] (Charter 5) Captures of the Timer screen at 390x844 and 1280x800 in light and dark (`tools/talos/screens.py`) are signed by Design QA as matching the approved mockups.
